# API — FODIP Digital 2030

Backend cible : NestJS + TypeScript + REST + OpenAPI, organisé en monolithe modulaire pour le MVP.

Modules prévus : auth, users, companies, applications, documents, scoring, committees, financing, disbursements, repayments, impact, programs, notifications, audit, reporting et administration.

Le code applicatif sera initialisé lors de l'étape Backend/API. PostgreSQL est le système de référence transactionnel.
